# 집필

그림으로 보는 설정 안내: https://claude.ai/artifact/SMoN9a3GdwGk6LLeNVAH1z (본인만 열 수 있어요)

구글 드라이브에 원고를 저장하는 소설 집필 웹 편집기예요. 데스크톱과 휴대폰 브라우저에서 같은 주소로 써요.
AI 기능은 넣지 않았어요. 집필 도움은 Claude 대화창에서 드라이브의 원고를 읽혀서 받아요.

- 주소(설정 후): https://wad397.github.io/novel/
- 원고 위치: 내 드라이브 › `내소설` › `작품 제목` › `설정.md`, `001 - 회차제목.md` …

## 처음 한 번만 하는 설정

### 1. GitHub Pages 켜기
1. 이 저장소 → **Settings** → 왼쪽 **Pages**
2. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → Save
3. 1~2분 뒤 https://wad397.github.io/novel/ 이 열리면 성공이에요. 아직은 "CLIENT_ID가 비어 있어요"라고 나와요.

### 2. 구글 로그인용 ID 만들기
1. https://console.cloud.google.com 접속 → 위쪽 프로젝트 선택 → **새 프로젝트** (이름 예: 집필)
2. **API 및 서비스 › 라이브러리**에서 "Google Drive API" 검색 → **사용**
3. **Google 인증 플랫폼(OAuth 동의 화면)** → 시작하기
   - 앱 이름: 집필, 지원 이메일: 내 이메일
   - 대상: **외부(External)**
4. **대상(Audience)** › 테스트 사용자 › **사용자 추가** → 내 구글 이메일
5. **클라이언트** › 클라이언트 만들기
   - 유형: **웹 애플리케이션**
   - 승인된 JavaScript 원본: `https://wad397.github.io`
   - 만들기 → 나오는 **클라이언트 ID**(`…apps.googleusercontent.com`) 복사

### 3. 클라이언트 ID 넣기
`app.js` 맨 위의 `const CLIENT_ID = '';` 따옴표 안에 붙여넣고 저장(커밋)해요. GitHub 웹에서 파일 열고 연필 버튼으로 고쳐도 되고, Claude에게 부탁해도 돼요.

처음 로그인할 때 **"Google에서 확인하지 않은 앱"** 경고가 나와요. 내가 만든 앱이라 괜찮아요. **고급 › 집필(으)로 이동**을 누르면 돼요.

## 쓰는 법
- 작품 만들기 → 회차 만들기 → 쓰기. 입력을 멈추고 2초 뒤 자동 저장돼요.
- **로그인 만료**(약 1시간): 위에 빨간 띠가 떠요. 쓴 글은 그 기기에 보관돼 있으니 **다시 로그인**을 누르면 이어서 저장돼요.
- **두 기기 충돌**: 다른 기기에서 먼저 고친 회차는 덮어쓰지 않아요. 지금 글은 `001 - 제목 (충돌 날짜).md` 사본으로 저장돼요. 두 개를 비교해서 합친 뒤 필요 없는 쪽을 삭제하세요.
- 삭제한 회차는 드라이브 휴지통으로 가요.
- **설정 파일**: 작품을 만들면 `설정.md`(작품 정보·인물 카드·끝 장면 메모·피드백 양식), 회차를 만들면 `001 설정.md`(그 화의 요청서 양식)가 함께 생겨요. 편집기 설명판에서 보고 **고치기**로 채워요. Claude에게 물을 때 둘 다 같이 복사돼요.

## Claude와 함께 쓰기

### 편집기에서 바로 (추가 요금 없음)
1. **설정 › Claude 컨셉**에 Claude가 맡을 역할과 말투를 적어 둬요. 예: "너는 20년 차 장르소설 편집자 '윤 편집장'이다…"
2. 편집기 설명판의 **Claude에게 묻기** → 부탁할 일(**설정대로 이번 화 쓰기** 등)을 고르고 **복사하기** → **Claude 열기** → 붙여 넣고 보내요.
   본문, 작품 설정, 이번 화 설정, 컨셉, 답하는 형식이 함께 복사돼요. **설정 › Claude 프로젝트**에 프로젝트 주소를 넣어 두면 늘 그 프로젝트가 열려요.
3. Claude가 수정본이나 이어 쓴 장면을 주면 답 전체를 복사해서 **수정본 반영**에 붙여 넣어요.
   바뀐 곳을 표시해서 보여 주고, **반영하기**를 누르면 원고에 들어가요. Ctrl+Z로 되돌릴 수 있어요.

### Claude Code 대화창에서
Claude Code 대화창에서는 이렇게 부탁하면 돼요.

- "5화에서 설정이랑 어긋나는 부분 찾아줘"
- "2화 맞춤법·문장 다듬어서 그 파일에 바로 반영해줘"

앱은 자기가 만든 파일만 볼 수 있어요. 그래서 Claude가 **새 파일**을 만들면 앱 목록에 보이지 않아요. 새 회차는 앱에서 먼저 만들고, Claude에게는 그 파일을 고쳐 달라고 하세요.
